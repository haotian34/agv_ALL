# 二维平面标定

| 文件 | 代码作用 |
|---|---|
| `plane_calibrate.py` | 采集A4九点标定数据 |
| `plane_math.py` | 位姿、单应矩阵和平面数学计算 |
| `plane_session.py` | 保存和读取标定会话 |
| `plane_locate.py` | 使用标定配置计算像素对应的静态位置 |
| `plane_report.py` | 输出标定报告 |
| `plane_profiles.json` | 标定配置 |
| `PLANE_CALIBRATION_GUIDE.md` | 九点标定操作说明 |
| `test_*.py` | 离线单元测试 |
